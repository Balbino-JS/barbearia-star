# 💈 Barber Shop Website

Este é o site institucional desenvolvido para a **GILDED BARBERS**. O projeto foi criado para oferecer uma interface moderna, rápida e funcional para os clientes da barbearia.

## 🚀 Tecnologias Utilizadas
- **Frontend:** HTML5, JavaScript
- **Estilização:** CSS

## 🛠️ Funcionalidades
- **Landing Page:** Seção de boas-vindas com a proposta da marca.
- **Serviços:** Listagem dinâmica de cortes e tratamentos.
- **Galeria:** Exibição de trabalhos realizados.
- **Responsividade:** Adaptado para qualquer tamanho de tela.
